# เว็บจัดตารางเรียนส่วนตัว — Design (ฉบับสั้น)
ให้claude วางแผน

## จุดประสงค์
วางแผนตารางเรียนก่อนลงทะเบียน: ใส่ทุก Section ที่เปิดของแต่ละวิชา แล้วเลือกวิชาละ 1 Section ให้ได้ตารางที่ไม่ชนกัน

## เป้าหมาย
- เพิ่ม/แก้/ลบ วิชา, Section และคาบเรียนได้
- เลือกวิชาละ 1 Section พอดี (แต่ละวิชาเลือกคนละ Section ได้) และต้องเลือกครบทุกวิชา
- แสดงตารางเป็นกริด 6 วัน (จันทร์–เสาร์) × 4 ช่วงเวลา
- เตือนเมื่อเวลาชน และบอกว่าวิชาไหนยังไม่ได้เลือก Section

## ไม่ทำในรอบแรก (ค่อยเพิ่มทีหลัง)
- หาชุด Section ที่ไม่ชนกันให้อัตโนมัติ
- ซิงก์ข้าม device / ระบบล็อกอิน
- เวลาเรียนแบบกำหนดเอง (นอกเหนือจาก 4 ช่วง)

## ข้อมูล
- **วิชา**: รหัสวิชา (บังคับ, ห้ามซ้ำ), ชื่อวิชา (ไม่บังคับ แก้ทีหลังได้), Section ที่เลือก
- **Section**: เลข Section (บังคับ, ห้ามซ้ำภายในวิชาเดียวกัน แต่ซ้ำกับวิชาอื่นได้) — รูปแบบ **ตัวเลข 3 ตัว + ตัวอักษร A–F 1 ตัว** เช่น `101A` (พิมพ์ตัวเล็ก/เว้นวรรคได้ ระบบแปลงให้)
- **คาบเรียน**: Section หนึ่งมี **1 คาบพอดี** (ผู้ใช้ยืนยัน 21 พ.ย. 2569) — วัน (จ.–ส.), ช่วงเวลา (8:40-11:00 / 12:00-14:20 / 14:30-16:50 / 17:00-19:20), ห้อง (**ไม่บังคับ**), ประเภท Lab/Lect (ไม่บังคับ)
- รหัสวิชาเทียบแบบไม่สนตัวพิมพ์/ช่องว่าง (`cs101` = `CS101`)
- ลบวิชา/Section ต้องมีกล่องยืนยันก่อน
- git: เริ่มบันทึกหลังเวอร์ชันแรก (App 1.0) เสร็จ

## กฎ
- **เวลาชน**: คาบของ Section ที่เลือกไว้ตั้งแต่ 2 คาบขึ้นไปตรงกับวันและช่วงเวลาเดียวกัน → ไฮไลต์สีแดงทั้งในตารางและในรายการ
- **ยังเลือกไม่ครบ**: มีวิชาที่ยังไม่ได้เลือก Section → แสดงรายชื่อวิชานั้น
- ไม่ห้ามบันทึกตอนที่เวลาชน แค่เตือน (จะได้ลองสลับ Section ดูได้)

## วิธีที่พิจารณา
- **A. HTML ไฟล์เดียว + JavaScript ธรรมดา + localStorage** — ✅ **เลือกอันนี้** เพราะง่ายที่สุด เปิดได้เลยโดยไม่ต้องติดตั้งอะไร
- B. Vite + React/Vue — โครงสร้างดีกว่าเมื่อเว็บโตขึ้น แต่ต้องติดตั้ง Node.js และมีขั้นตอน build
- C. ใช้ฐานข้อมูลออนไลน์ (Firebase/Supabase) — ซิงก์ข้ามเครื่องได้ แต่ตั้งค่ายุ่ง ตอนนี้ยังไม่จำเป็น

## เทคนิค
- ไฟล์: `index.html`, `style.css`, `app.js` (ไม่มี library ภายนอก, ไม่ต้อง build)
- บันทึกอัตโนมัติลง `localStorage` ทุกครั้งที่ข้อมูลเปลี่ยน
- ปุ่ม Export/Import เป็นไฟล์ JSON ไว้สำรองข้อมูลหรือย้ายเครื่อง
- หน้าเว็บภาษาไทย ใช้บนมือถือได้ (ตารางเลื่อนแนวนอนได้)

## เรื่องที่ผมตัดสินใจเอง (แก้ได้)
- ~~Section หนึ่งมีได้หลายคาบ~~ → เปลี่ยนเป็น 1 คาบต่อ Section ตามที่ผู้ใช้กำหนด (Figma V2 ยังวาดแบบหลายคาบไว้ ให้ถือ spec นี้เป็นหลัก)

- หน้าตา: ด้านซ้ายเป็นรายการวิชา/Section (เลือก Section ด้วยปุ่มเลือกแบบ radio) ด้านขวาเป็นตาราง บนมือถือจะเรียงบน-ล่าง
