# My Scheduling — เว็บจัดตารางเรียนส่วนตัว

ใส่ทุก Section ที่เปิดสอนของแต่ละวิชา แล้วเลือกวิชาละ 1 Section เว็บจะแสดงตารางเรียน จันทร์–เสาร์ × 4 คาบ เตือนเมื่อเวลาชน และแนะนำ Section ที่สลับแล้วไม่ชน

- ไม่ต้องติดตั้งโปรแกรม ไม่ต้องสมัครสมาชิก
- ข้อมูลเก็บในเบราว์เซอร์ของคุณเอง ไม่ส่งขึ้นเซิร์ฟเวอร์

## วิธีโหลดไปใช้งาน

### แบบที่ 1: ดาวน์โหลด ZIP (ง่ายที่สุด)

1. ที่หน้านี้บน GitHub กดปุ่มสีเขียว **Code** → **Download ZIP**
2. แตกไฟล์ ZIP (คลิกขวา → **Extract All…**)
3. เปิดโฟลเดอร์ `App 1.0` แล้ว**ดับเบิลคลิก `index.html`** เว็บจะเปิดในเบราว์เซอร์ทันที

### แบบที่ 2: ใช้ Git

```bash
git clone https://github.com/FmilyDev/My-Scheduling.git
```

จากนั้นเปิดไฟล์ `My-Scheduling/App 1.0/index.html` ในเบราว์เซอร์

> ใช้ได้กับ Chrome, Edge, Firefox และ Safari เวอร์ชันใหม่ ถ้าไม่ได้ต่ออินเทอร์เน็ต เว็บยังใช้ได้ปกติ แค่ฟอนต์จะเปลี่ยนเป็นฟอนต์ของเครื่อง

## วิธีใช้

1. กด **+ เพิ่มวิชา** แล้วกรอก
   - **รหัสวิชา** (บังคับ ห้ามซ้ำ)
   - **ชื่อวิชา** (ไม่บังคับ ใส่ทีหลังได้)
   - **ประเภทวิชา** Lect / Lab (ไม่บังคับ ใช้กับทุก Section ของวิชานั้น)
2. ใส่ทุก **Section** ที่เปิดสอน — แต่ละ Section มี 1 คาบ
   - **เลข Section**: ตัวเลข 3 ตัวตามด้วย A–F เช่น `101A` (ห้ามซ้ำในวิชาเดียวกัน แต่ซ้ำกับวิชาอื่นได้)
   - **วัน**: จันทร์–เสาร์
   - **ช่วงเวลา**: 8:40–11:00 / 12:00–14:20 / 14:30–16:50 / 17:00–19:20
   - **ห้อง** (ไม่บังคับ)
3. ในรายการวิชา **เลือกวิชาละ 1 Section**
   - ชี้เมาส์ที่ Section เพื่อดูตัวอย่างในตาราง (เส้นประ) ว่าจะชนหรือไม่
4. ถ้าเวลาชน ช่องในตารางจะเป็นสีแดง — **กดที่ช่องนั้น** เพื่อดู Section ที่สลับแล้วไม่ชน แล้วกด **สลับ**
5. แถบด้านบนบอกว่าเลือกครบหรือยัง และวิชาไหนยังไม่ได้เลือก

## ข้อมูลของคุณ

- เว็บ**บันทึกอัตโนมัติ**ในเบราว์เซอร์ที่ใช้เปิด — ปิดแล้วเปิดใหม่ข้อมูลยังอยู่
- ข้อมูล**ไม่ย้ายตาม**ไปเครื่องอื่นหรือเบราว์เซอร์อื่น และจะหายถ้าล้างข้อมูลเบราว์เซอร์ (Clear browsing data) หรือใช้โหมดไม่ระบุตัวตน
- **สำรองข้อมูล**: กด **ส่งออก (Export)** จะได้ไฟล์ `ตารางเรียน-วันที่.json`
- **ย้ายเครื่อง / กู้คืน**: เปิดเว็บที่เครื่องใหม่ แล้วกด **นำเข้า (Import)** เลือกไฟล์ `.json` นั้น

## สำหรับนักพัฒนา

โค้ดเป็น HTML + CSS + JavaScript ล้วน ไม่มีขั้นตอน build

```
App 1.0/
  index.html      หน้าเว็บ
  style.css       หน้าตา (คอม + มือถือ)
  js/logic.js     กฎ, ตาราง, หาเวลาชน (ไม่แตะหน้าเว็บ)
  js/store.js     บันทึก localStorage + Export/Import
  js/app.js       วาดหน้าจอ + ปุ่มต่าง ๆ
  tests/          เทสต์ของ logic.js และ store.js
```

รันเทสต์ (ต้องมี Node.js 20 ขึ้นไป):

```bash
cd "App 1.0"
node --test tests/*.test.js
```
